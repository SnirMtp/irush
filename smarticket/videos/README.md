# videos/

Put the compressed clips here (output of `scripts/compress-videos.sh`):

- scene1_chaos.mp4 / scene1_chaos_mobile.mp4
- scene2_transition.mp4 / scene2_transition_mobile.mp4
- scene3_solution.mp4 / scene3_solution_mobile.mp4

The `_mobile` files are optional. If they're missing, the page falls back to the desktop file. If a scene has no video at all, a CSS animation driven by the scroll is shown instead.
